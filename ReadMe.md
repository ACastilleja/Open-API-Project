# BEACH WEATHER!

What does it do?
BEACH WEATHER is an OpenAPI project that fetches current and hourly weather data from open-meteo. Just click on the Current Weather or 5-hr Forecast button and off you go. 

#Note:

BEACH WEATHER is setup to search for Continental U.S.A. and Hawaii beaches and return their weather.  Unfortunately for now if you search for a beach that is outside of this area it might give you an error. My apologies.

# Installation

1. Open your terminal or command prompt and run the following command:
 git clone https://github.com/ACastilleja/Open-API-Project.git

2. Navigate to the Project Folder:
 cd Open-API-Project

3. Open the Project:
-Open the BEACH WEATHER app by opening the folder in VS Code and right-clicking on index.html and selecting "Open with Live Server".  
-You can also open it by simply double clicking the index.html file in your file explorer to view it in your browser. 

# Usage

1. Use either the My Beach or Weather Outlook navigation links at the top of the page to quickly move to the Beach Search area. 
2. Once in the Beach Search area just type in the name of the beach you would like to search for. Note: Beach must be withing the Continental USA or Hawaii. 
3. Next, just click on the Get Current Weather or Get 5-hr Forecast button and you should see the results within the Weather Outlook section of our app.
4. To Search for another beach simply click on the Reset Search button and enter the new beach name.
